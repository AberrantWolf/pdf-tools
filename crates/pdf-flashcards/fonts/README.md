# Embedded font

`NotoSansJP-Bold.ttf` is embedded into generated flashcard PDFs (and into the
crate binary via `include_bytes!`) to render card text, including CJK.

It is licensed under the **SIL Open Font License 1.1**, which permits embedding
the font in both documents and software. The full license is in
`OFL-NotoSansJP.txt`. Noto Sans JP derives from Adobe's Source Han Sans
(copyright Adobe, Reserved Font Name "Source"); it is embedded unmodified under
its original name, so the Reserved Font Name imposes no extra obligation.

Source: [Noto](https://github.com/notofonts), via
[google/fonts](https://github.com/google/fonts).
